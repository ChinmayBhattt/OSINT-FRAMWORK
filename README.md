# OSINT Framework

https://osintframework.com

## What it is
OSINT Framework is a curated collection of open-source intelligence resources focused on gathering information from free tools and services.
Some resources may require registration or offer paid tiers, but they generally provide at least some no-cost functionality.

## Purpose
- Help users quickly find relevant OSINT resources
- Organize tools by investigation target/use case
- Provide a practical navigation structure for recon and research workflows

## Typical categories on the framework
- Username
- Email Address
- Domain Name
- IP Address
- Social Networks
- Images / Videos / Documents
- Public Records / Business Records
- Dark Web and breach-related resources
- Geolocation and mapping
- Threat intelligence and technical investigation tools

## Legend used by the framework
- **(T)**: Tool must be installed/run locally
- **(D)**: Google Dork
- **(R)**: Requires registration
- **(M)**: URL must be edited manually with the search term

## Notes
- This framework is commonly used as a starting point during OSINT investigations.
- Always follow legal, ethical, and platform terms-of-service requirements when using OSINT tools.
